# Aula 04 — Tratamento Global de Exceções

## Objetivo

Implementar um servidor utilizando **Node.js e Express.js**, trabalhando com tratamento de exceções e erros de forma centralizada.

A atividade demonstra como lidar com:

- Erros síncronos;
- Erros assíncronos;
- Exceções não capturadas;
- Promises rejeitadas;
- Middleware global de tratamento de erros;
- Registro de erros no console.

## Tecnologias utilizadas

- Node.js
- Express.js
- JavaScript
- NPM
- Git e GitHub
