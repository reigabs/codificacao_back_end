# Aula 06 — Servidor Web

## Objetivo

Criar um servidor web utilizando o módulo nativo `http` do Node.js, trabalhando com requisições HTTP, rotas, códigos de status e cabeçalhos de resposta.

## Tecnologias utilizadas

- Node.js
- JavaScript
- Módulo `http`
- NPM
- Git e GitHub
